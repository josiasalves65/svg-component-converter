# ⚡ SVG to Component Converter

A fast, 100% browser-based tool to instantly convert raw SVG files into clean, production-ready React components with a live visual preview.

## 🚀 Live Demo
Check it out live here: [https://netlify.app](https://netlify.app)

## ✨ Features
- **Instant Preview:** View your icon dynamically before copying the code.
- **Clean Output:** Automatically removes Figma and Adobe Illustrator junk metadata.
- **React Friendly:** Translates standard SVG attributes into camelCase (e.g., `stroke-width` to `strokeWidth`).
- **Privacy Focused:** Runs entirely client-side. No servers, no sign-ups, no data tracking.

## 🛠️ Built With
- HTML5
- CSS3 (Custom Dark Theme Layout)
- Vanilla JavaScript (DOMParser & FileReader API)
